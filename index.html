What is kotlin-test

kotlin-test is the official Kotlin multiplatform testing library. It provides assertion functions and test annotations that work across JVM, JS, and Native targets. On JVM it integrates with JUnit4, JUnit5, or TestNG as the underlying runner. Add it with a single dependency:

// build.gradle.kts dependencies { testImplementation(kotlin(“test”)) } // The simplest Kotlin unit test import kotlin.test.* class CalculatorTest { @Test fun testAddition() { assertEquals(4, Calculator().add(2, 2)) } @Test fun testDivisionByZero() { assertFails { Calculator().divide(10, 0) } } }

kotlin-test assertions — assertEquals, assertNotNull, assertTrue, assertFails, assertFailsWith, expect — are available across all Kotlin targets without importing a JVM-specific library.
